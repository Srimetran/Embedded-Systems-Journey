# 🚀 Embedded Systems Journey

## About

Welcome to my Embedded Systems Journey.

I'm an Electrical & Computer Engineering student passionate about embedded systems, firmware development, and the intersection of hardware and software. This repository serves as a living engineering journal documenting my progression as I develop the skills required to become an embedded software engineer.

Rather than simply completing projects, my focus is on understanding the underlying engineering principles behind every concept I learn. I strive to build a strong foundation by studying how microcontrollers interact with hardware, how firmware is designed, and how efficient, reliable embedded software is developed.

Every milestone in this repository represents another step toward becoming a better engineer.

---

## My Goals

My long-term goal is to become a firmware engineer capable of designing reliable embedded software for real-world systems. Through consistent hands-on practice, I aim to develop a deep understanding of both low-level programming and hardware design.

Along this journey, I am working to master:

- Embedded C/C++
- Microcontroller Architecture
- GPIO and Peripheral Programming
- Digital & Analog Electronics
- Timers and Interrupts
- UART, SPI, and I²C Communication
- PWM and ADC
- State Machines
- Real-Time Embedded Systems
- RTOS Development
- Embedded Linux
- PCB Design
- Hardware Debugging
- Firmware Architecture
- Performance Optimization

## Engineering Philosophy

I believe the best way to learn embedded systems is by building.

Every concept I study is reinforced through hands-on experimentation, debugging, documentation, and continuous improvement. Rather than treating mistakes as setbacks, I view them as opportunities to better understand how embedded systems work.

This repository reflects not only completed work, but also my growth as an engineer and my commitment to lifelong learning.
